# 🌹 Para Hilly — Cumpleaños 14 de septiembre

Micrositio de cumpleaños hecho con **HTML + CSS + JavaScript puro**, preparado para publicarse gratis con GitHub Pages.

## Archivos

- `index.html` — estructura y textos.
- `style.css` — diseño, animaciones y versión móvil.
- `script.js` — cuenta regresiva, carta, regalo y confeti.

## Publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo: `hilly-cumpleanos`.
2. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique la página.
7. GitHub te dará una dirección parecida a:
   `https://TU-USUARIO.github.io/hilly-cumpleanos/`
